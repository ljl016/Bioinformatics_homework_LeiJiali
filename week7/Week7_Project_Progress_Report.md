## 一、项目目的与科学问题

人体骨骼肌在训练（growth）、停练（detraining）、废用（disuse）与再次恢复（reloading / re-ULLS）过程中的**分子适应是否存在持续性**？再次响应是否改变？这是课程全部 5 个数据集共同回应的核心。

具体研究问题（精简计划 PART 1）：

- RQ1：训练 / 停练 / 废用引起的分子变化，哪些恢复、哪些持续？
- RQ2：再次训练 / 再次废用的响应是否与首次不同？
- RQ3：训练史（training history）对长期残余与再训练响应的影响？
- RQ4：同一人同阶段 RNA 与甲基化（RRBS）是否相容？
- RQ5：D1（Turner）的发现能否在 D5（GSE211204）独立人群中复现？

边界（精简计划 §1.7）：不引入新数据集 / 新组学 / 不重处理 FASTQ·BAM·原始 IDAT；不拼合跨组学矩阵；不引入 MOFA / WGCNA / ML；阴性 / 不确定 / 相反结果视为完整结果；不因显著性反复调参。

- §1.2："分子记忆"是**待研究问题**不是前提；不预写结论；不写因果机制。
